# I18N-001: Keep text in DOM for browser translation

User-facing text must be in DOM text nodes, not in attributes, so browser translation tools (Google Translate, Safari Translate) can access it.

**Do:**

```ts
// Text in DOM — translatable
render() {
  return html`
    <button>
      <span class="visually-hidden">Search for providers</span>
      <${this.scope.tag('icon')} name="search"></${this.scope.tag('icon')}>
    </button>
    
    <p>No providers found in your area.</p>
    
    <label for="zip">ZIP code</label>
    <input id="zip" type="text" />
  `;
}
```

The label component has a visually hidden label built into it.

```ts
<zd-button>
  <zd-icon name="search" label="Search for providers"></zd-icon>
</zd-icon>
```

**Don't:**

```ts
// ❌ Text in aria-label — not translated by browser tools
<button aria-label="Search for providers">
  <zd-icon name="search"></zd-icon>
</button>

// ❌ Text in title attribute
<button title="Search">...</button>

// ❌ Text in placeholder only
<input placeholder="Enter ZIP code" />
```

For icon-only buttons, use visually hidden text in the DOM rather than `aria-label`. This pairs with [A11Y-004](../accessibility/A11Y-004.md)'s requirement for visible labels.

See also: [I18N-002](./I18N-002.md), [A11Y-004](../accessibility/A11Y-004.md)
