# I18N-004: Don't split translatable text across elements

Keep translatable phrases as single text nodes. Splitting them across elements breaks translation tools and produces grammatically incorrect translations.

**Do:**

```ts
// Single text node — translates as a phrase
render() {
  return html`
    <p>Found ${this.count} providers in your area</p>
    <p>Showing availability for ${this.providerName}</p>
  `;
}

// If you need to style part of it, use a span but keep it in one parent
render() {
  return html`
    <p>
      <span class="count">${this.count}</span> providers found
    </p>
  `;
}
```

**Don't:**

```ts
// ❌ Split across siblings — translator sees "Found" and "providers" separately
render() {
  return html`
    <span>Found</span>
    <span class="count">${this.count}</span>
    <span>providers</span>
  `;
}

// ❌ Concatenated — translation tools can't see the template
const message = 'Found ' + count + ' providers';
```

The issue: translators see "Found" and "providers" as separate strings. In German, "providers" might be "Anbieter" or "Anbietern" depending on count — the translator can't know which without seeing the full phrase.
