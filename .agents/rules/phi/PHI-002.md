# PHI-002: Test data from documented scenarios only

No patient data in committed fixtures, stories, or test files. Tests and stories use the documented scenarios from `https://api-docs.zocdoc.com/guides/testing-data`.

**Do:**

```ts
// Use documented test data
const testPatient = {
  first_name: 'Test',
  last_name: 'Patient',
  date_of_birth: '1990-01-15',
  sex_at_birth: 'female',
  phone_number: '2125551234',
  email_address: 'test@example.com',
  patient_address: {
    address1: '123 Test Street',
    city: 'New York',
    state: 'NY',
    zip_code: '10001',
  },
};

// Reference the source
// Test data per https://api-docs.zocdoc.com/guides/testing-data
```

**Don't:**

```ts
// ❌ Real-looking names that could be confused with PHI
const testPatient = {
  first_name: 'John',
  last_name: 'Smith',
  phone_number: '2128675309', // real-looking number
};

// ❌ Data from production logs or real appointments
const fixturePatient = productionPatientData;
```

Stories render against the live sandbox using the configured `.env.local` token. Sandbox responses may contain test provider data, which is safe. Never configure a production token in stories.
