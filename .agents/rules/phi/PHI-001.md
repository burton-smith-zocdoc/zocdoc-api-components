# PHI-001: No PHI in logs, errors, or messages

`zd-patient-form` collects Protected Health Information (PHI) by definition. Patient field values must never appear in:

- `console.log`, `console.error`, or any logging
- Error messages or thrown error bodies
- Network error details exposed to consumers
- Debug output in development builds

**Do:**

```ts
// Log action, not data
console.log('Patient form submitted');

// Errors reference field names, not values
if (!formData.email_address) {
  throw new Error('email_address is required');
}

// Redact in error boundaries
catch (error) {
  this.emit('error', { 
    detail: { message: 'Form submission failed', code: 'SUBMIT_ERROR' }
  });
}
```

**Don't:**

```ts
// ❌ Patient data in console
console.log('Submitting patient:', patientData);

// ❌ Patient data in error
throw new Error(`Invalid email: ${formData.email_address}`);

// ❌ Patient data in debug
console.debug('Form state:', JSON.stringify(this.formValues));
```

PHI includes: patient names, dates of birth, email addresses, phone numbers, addresses, and any data that could identify a patient or relate to their care.
