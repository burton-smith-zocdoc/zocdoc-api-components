# PHI-003: No analytics or third-party network calls

No telemetry, analytics, or third-party network calls anywhere in these packages. The only outbound destination is the configured Zocdoc `baseUrl`.

This ensures:
- PHI cannot leak to third parties
- The security boundary is clear and auditable
- Consumer trust: installing these components adds no tracking

**Do:**

```ts
// Only destination is the configured API
const config = getConfig();
fetch(`${config.baseUrl}/v1/appointments`, { ... });
```

**Don't:**

```ts
// ❌ Analytics
gtag('event', 'booking_complete', { provider_id: '123' });

// ❌ Error tracking
Sentry.captureException(error);

// ❌ Third-party services
await fetch('https://api.example.com/log', { body: eventData });

// ❌ Beacon/pixel
navigator.sendBeacon('https://tracking.example.com', data);
```

If consumers want analytics, they listen for the component events (`booking-complete`, `provider-select`, etc.) and send their own telemetry with appropriate consent and redaction.
