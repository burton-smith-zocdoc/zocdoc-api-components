# A11Y-005: Test every component with axe-core

Every component must have an accessibility test that runs axe-core against its rendered output. This catches common violations automatically.

**Do:**

```ts
import axe from 'axe-core';

describe('ZdProviderSearch', () => {
  describe('Accessibility', () => {
    it('has no axe violations in idle state', async () => {
      const { container } = await render(
        html`<zd-provider-search></zd-provider-search>`
      );
      const results = await axe.run(container);
      expect(results.violations).toEqual([]);
    });
    
    it('has no axe violations in error state', async () => {
      // Mock error state
      vi.spyOn(providerLocations, 'searchProviderLocations')
        .mockRejectedValue(new ZocdocError('Failed', 500));
      
      const { container } = await render(
        html`<zd-provider-search zip-code="10011"></zd-provider-search>`
      );
      await el.search();
      await el.updateComplete;
      
      const results = await axe.run(container);
      expect(results.violations).toEqual([]);
    });
  });
});
```

Test multiple states — axe violations can appear only in specific states (error messages without proper association, loading states without announcements).

**Don't:**

```ts
// ❌ Only testing default state
it('has no violations', async () => {
  const { container } = await render(html`<zd-patient-form></zd-patient-form>`);
  expect(await axe.run(container)).toHaveNoViolations();
  // Never tests the form with validation errors shown
});
```
