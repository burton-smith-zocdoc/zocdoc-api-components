# A11Y-002: Announce state changes to screen readers

Loading, success, empty, and error states must be announced. Use `aria-live` regions or Charm's built-in announcement patterns.

**Do:**

```ts
render() {
  return html`
    <div role="status" aria-live="polite" aria-atomic="true">
      ${this.state === 'loading' ? html`<span>Loading providers...</span>` : nothing}
      ${this.state === 'empty' ? html`<span>No providers found in your area.</span>` : nothing}
    </div>
    
    <div role="alert" aria-live="assertive">
      ${this.state === 'error' ? html`<span>Error: ${this.errorMessage}</span>` : nothing}
    </div>
    
    ${this.state === 'success' ? this.renderResults() : nothing}
  `;
}
```

| State | Region | Priority |
|-------|--------|----------|
| `loading` | `role="status"` + `aria-live="polite"` | Announced when convenient |
| `empty` | `role="status"` + `aria-live="polite"` | Announced when convenient |
| `error` | `role="alert"` + `aria-live="assertive"` | Announced immediately |
| `success` | No announcement needed | User navigates to results |

**Don't:**

```ts
// ❌ Visual-only state change — screen readers see nothing
render() {
  if (this.loading) return html`<div class="spinner"></div>`;
}

// ❌ Assertive for non-critical updates — interrupts user
<div aria-live="assertive">${this.loading ? 'Loading...' : ''}</div>
```
