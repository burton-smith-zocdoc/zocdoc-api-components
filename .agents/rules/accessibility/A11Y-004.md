# A11Y-004: Form accessibility in patient-form

`zd-patient-form` collects ten fields. Every field must have:

1. **Visible label** — not just placeholder text
2. **Error association** — `aria-describedby` pointing to error message
3. **Required indication** — `aria-required="true"` on required fields
4. **Logical grouping** — fieldsets for related fields (address, contact)

**Do:**

```ts
render() {
  return html`
    <form>
      <fieldset>
        <legend>Contact Information</legend>
        
        <${this.scope.tag('input')}
          id="email"
          label="Email address"
          type="email"
          required
          aria-required="true"
          aria-invalid=${this.errors.email ? 'true' : 'false'}
          aria-describedby=${this.errors.email ? 'email-error' : nothing}
          @change=${this.#handleEmailChange}
        ></${this.scope.tag('input')}>
        
        ${this.errors.email ? html`
          <span id="email-error" class="error" role="alert">
            ${this.errors.email}
          </span>
        ` : nothing}
      </fieldset>
      
      <fieldset>
        <legend>Address</legend>
        <!-- address1, city, state, zip_code -->
      </fieldset>
    </form>
  `;
}
```

**Don't:**

```ts
// ❌ Placeholder as label — disappears on input, not announced
<input placeholder="Email address" />

// ❌ Error without association — screen reader doesn't know what it's for
<input id="email" />
<span class="error">${this.errors.email}</span>

// ❌ Visual-only required indicator
<label>Email *</label>  // The * means nothing to screen readers
```

Charm's `input` component handles label association automatically when you pass the `label` prop.
