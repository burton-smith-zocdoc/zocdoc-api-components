# Internationalization Rules (I18N)

When building components or writing styles, follow these i18n rules. For full details and examples, see the linked rule files.

- **I18N-001** Keep text in DOM for browser translation — user-facing text in DOM text nodes, not attributes like `aria-label` or `placeholder`. ([details](../../.agents/rules/i18n/I18N-001.md))
- **I18N-002** Use Intl APIs for dates, times, and numbers — `Intl.DateTimeFormat`, `Intl.RelativeTimeFormat`, not string concatenation. ([details](../../.agents/rules/i18n/I18N-002.md))
- **I18N-003** Use CSS logical properties for RTL — `margin-inline-start` not `margin-left`, `inset-inline-end` not `right`. ([details](../../.agents/rules/i18n/I18N-003.md))
- **I18N-004** Don't split translatable text across elements — keep phrases in single text nodes for proper translation. ([details](../../.agents/rules/i18n/I18N-004.md))
