## Package Installation

Install the components package and its peer dependencies:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
</Tabs>

## Required CSS

The component bundle does not include the Zocdoc theme stylesheet. Import it separately before using the components:

```javascript
import '@zocdoc/api-primitive-components/theme/all.css';
```

Or load it from the CDN with a `<link>` tag in the document `<head>`:

```html
<link
  rel="stylesheet"
  href="https://unpkg.com/@zocdoc/api-primitive-components/dist/theme/all.css"
/>
```

This stylesheet includes the design tokens, reset, and utility classes used by the components. If you need to preserve existing global styles, load `theme/tokens.css` and `theme/utilities.css` separately and apply the reset only where appropriate. Each is also available from the CDN under `dist/theme/`.

## Script Tag Alternative

For pages without a build step, load one of the prebuilt bundles. Use the IIFE bundle as a classic script:

```html
<link
  rel="stylesheet"
  href="https://unpkg.com/@zocdoc/api-primitive-components/dist/theme/all.css"
/>
<script
  src="https://unpkg.com/@zocdoc/api-components/bundle/iife"
  zd-token="TOKEN_FROM_YOUR_BACKEND"
></script>
```

Or use the ESM bundle as a module script:

```html
<link
  rel="stylesheet"
  href="https://unpkg.com/@zocdoc/api-primitive-components/dist/theme/all.css"
/>
<script
  type="module"
  src="https://unpkg.com/@zocdoc/api-components/bundle"
  zd-token="TOKEN_FROM_YOUR_BACKEND"
></script>
```

Either one registers all components and configures the client from its own `<script>` tag:

| Attribute     | Effect                                                                            |
| ------------- | --------------------------------------------------------------------------------- |
| `zd-token`    | API token for live requests. Takes precedence over `zd-mock`.                     |
| `zd-base-url` | API environment. Defaults to `https://api-developer-sandbox.zocdoc.com`.          |
| `zd-mock`     | Serves sample data with no network calls. Only applies when `zd-token` is absent. |

The attributes are read once, when the bundle runs. A token that expires needs `configureZocdoc({ baseUrl, getToken })` with a function instead. The IIFE bundle exposes it as `Zocdoc.configureZocdoc`, and the ESM bundle exports it.

The ESM bundle finds its tag by matching the tag's `src` to its own URL. If a CDN redirects that URL, it falls back to the only module script with a `zd-*` attribute. With more than one such script on the page, it configures nothing, so call `configureZocdoc()` yourself. A bundle loaded with `import` rather than a `<script>` tag never reads attributes.

Neither bundle includes theme CSS, so keep the `<link>` tag shown in both examples.

## TypeScript

The packages include TypeScript definitions. For component types:

```typescript
import type { ProviderLocation, Timeslot, Appointment } from '@zocdoc/api-components';
```

For typed elements in React, Vue, Svelte, or other JSX frameworks, see [Framework Integration](/zocdoc-api-components/guides/frameworks/).
