## Package Installation

Install the components package and its peer dependencies:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
</Tabs>

## Required CSS

The component bundle does not include the Zocdoc theme stylesheet. Import it separately before using the components:

```javascript
import '@zocdoc/api-primitive-components/theme/all.css';
```

This stylesheet includes the design tokens, reset, and utility classes used by the components. If you need to preserve existing global styles, import `theme/tokens.css` and `theme/utilities.css` separately and apply the reset only where appropriate.

## Script Tag Alternative

For pages without a build step, use the IIFE bundle:

```html
<script src="https://unpkg.com/@zocdoc/api-components/bundle/iife"></script>
```

This registers all components globally, but it does not include theme CSS. Load `@zocdoc/api-primitive-components/theme/all.css` separately as described above.

## TypeScript

The packages include TypeScript definitions. For component types:

```typescript
import type { ProviderLocation, Timeslot, Appointment } from '@zocdoc/api-components';
```

## Next Steps
