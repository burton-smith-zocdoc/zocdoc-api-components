## Package Installation

Install the components package and its peer dependencies:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @zocdoc/api-components @zocdoc/api-primitive-components
    ```
  </TabItem>
</Tabs>

## Required CSS

Import the theme reset and utilities before using any components:

```javascript
import '@zocdoc/api-primitive-components/theme/reset.css';
import '@zocdoc/api-primitive-components/theme/utilities.css';
```

These provide CSS custom properties that all components resolve against. Without them, components will render with missing styles.

## Script Tag Alternative

For pages without a build step, use the IIFE bundle:

```html
<script src="https://unpkg.com/@zocdoc/api-components/bundle/iife"></script>
```

This registers all components globally and includes the required CSS.

## TypeScript

The packages include TypeScript definitions. For component types:

```typescript
import type { ProviderLocation, Timeslot, Appointment } from '@zocdoc/api-components';
```

## Next Steps

Once installed, [configure the client](/zocdoc-api-components/getting-started/quick-start/) with your API credentials.
