A divider creates a visual boundary between related regions. Use a horizontal divider between stacked content, or a vertical divider between inline items; an optional slotted label can describe the separation.

## Usage

### Labelled horizontal divider

```html preview
<zd-grid gap="16">
  <p>Continue with an existing option.</p>
  <zd-divider>or</zd-divider>
  <p>Choose a different option.</p>
</zd-grid>
```

Use a short label only when it clarifies the relationship between the surrounding sections.

### Vertical separation

```html preview
<zd-flex gap="16" align="center" style="min-height: 2rem;">
  <span>Compact</span>
  <zd-divider orientation="vertical"></zd-divider>
  <span>Comfortable</span>
</zd-flex>
```

A vertical divider needs enough block size to be visible. Prefer layout gap for spacing and use the divider only for the visual boundary.
