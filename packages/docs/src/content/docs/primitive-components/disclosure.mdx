A disclosure reveals or hides supplementary content from a trigger. Put an interactive control in the `trigger` slot and the content to reveal in the default slot.

## Usage

### Reveal supplementary information

```html preview
<zd-disclosure>
  <zd-button slot="trigger" variant="link">Show additional details</zd-button>
  <p>This content becomes available when the trigger is activated.</p>
</zd-disclosure>
```

The trigger remains the user’s way to expand or collapse the content. Keep the trigger wording descriptive and the revealed text close to its context.

### Start expanded

```html preview
<zd-disclosure open>
  <zd-button slot="trigger" variant="link">Hide advanced options</zd-button>
  <p>Advanced options are currently visible.</p>
</zd-disclosure>
```

Set `open` when the initial state should be expanded. The disclosure emits show and hide events as its state changes.
