Use an alert to bring important feedback into the page flow. Choose a visual `variant`, write the message so its meaning is clear without relying on color, and set `politeness` according to whether assistive technology should announce it.

## Usage

### Feedback severity

```html preview
<zd-grid gap="12">
  <zd-alert open variant="info" politeness="polite">Your preferences are saved.</zd-alert>
  <zd-alert open variant="success" politeness="polite" heading="Changes saved">
    You can continue whenever you're ready.
  </zd-alert>
  <zd-alert open variant="warning" politeness="polite" heading="Review required">
    Check the highlighted settings before continuing.
  </zd-alert>
  <zd-alert open variant="danger" politeness="assertive" heading="Action not completed">
    Please review the information and try again.
  </zd-alert>
</zd-grid>
```

A variant changes presentation; it does not set the announcement behavior. Use `assertive` for an urgent, newly surfaced error and `polite` for routine updates.

### Dismissible alert with an action

```html preview
<zd-alert open dismissible variant="warning" heading="Some settings are incomplete">
  Review the required fields before continuing.
  <zd-button slot="action" variant="secondary" size="small">Review settings</zd-button>
</zd-alert>
```

The `action` slot can contain a related control. Dismissible alerts include a close button; keep the message understandable if a reader dismisses it.
