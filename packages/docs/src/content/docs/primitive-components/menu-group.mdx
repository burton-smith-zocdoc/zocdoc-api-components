A menu group organizes related `zd-menu-item` elements under a heading. It is typically used inside `zd-menu`, where the menu provides the trigger and popup behavior.

## Usage

### Grouped single-selection choices

```html preview
<zd-menu placement="bottom-start">
  <zd-button slot="trigger" variant="secondary">Visit format</zd-button>
  <zd-menu-group heading="Choose a format" select="single">
    <zd-menu-item>In person</zd-menu-item>
    <zd-menu-item>Video call</zd-menu-item>
  </zd-menu-group>
</zd-menu>
```

The group heading supplies context, and `select="single"` makes the options a one-at-a-time selection. Use `multiple` for independent selections.
