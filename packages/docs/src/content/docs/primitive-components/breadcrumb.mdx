Breadcrumbs show a reader’s location within a hierarchy and provide links back to earlier levels. Place `zd-breadcrumb-item` elements in order; the breadcrumb manages separators and marks the final item as current.

## Usage

### A three-level hierarchy

```html preview
<zd-breadcrumb label="Breadcrumb">
  <zd-breadcrumb-item href="/">Home</zd-breadcrumb-item>
  <zd-breadcrumb-item href="/services/">Services</zd-breadcrumb-item>
  <zd-breadcrumb-item>Preferences</zd-breadcrumb-item>
</zd-breadcrumb>
```

Give earlier items working destinations in your application. The final item is plain text because it represents the current page.
