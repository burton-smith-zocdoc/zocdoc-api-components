A tab panel holds the content associated with a `zd-tab`. Place tabs and panels in matching order inside `zd-tabs`; the parent displays the selected panel and coordinates keyboard behavior.

## Usage

### Panels paired with tabs

```html preview
<zd-tabs>
  <zd-tab>Overview</zd-tab>
  <zd-tab-panel>Summary information appears in this panel.</zd-tab-panel>
  <zd-tab>Details</zd-tab>
  <zd-tab-panel>Additional details appear in this panel.</zd-tab-panel>
</zd-tabs>
```

The panel content should correspond to its tab label. Keep essential content available through another route if a tab interface is not appropriate for the page.
