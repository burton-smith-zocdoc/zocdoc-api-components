A radio group manages one selection from several related `zd-radio` options. Provide a visible `label`, give the group a `name`, and use `layout` to choose a horizontal or vertical arrangement.

## Usage

### Labeled selection with helper text

```html preview
<zd-radio-group label="Choose a display mode" name="display-mode" value="list"
  help-text="You can change this preference later.">
  <zd-radio value="list">List</zd-radio>
  <zd-radio value="grid">Grid</zd-radio>
  <zd-radio value="compact">Compact list</zd-radio>
</zd-radio-group>
```

The group coordinates child radios, exposes a single value, and supports normal keyboard navigation. Use `horizontal` when the options fit comfortably on one line.

### Horizontal options and validation

```html preview
<zd-radio-group label="Choose a time range" name="time-range" layout="horizontal" required
  invalid error-message="Choose one range to continue.">
  <zd-radio value="week">One week</zd-radio>
  <zd-radio value="month">One month</zd-radio>
</zd-radio-group>
```

Set invalid feedback from the form’s validation state, and explain how to resolve the error.
