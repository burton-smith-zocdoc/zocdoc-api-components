Use `zd-scoped-styles` to apply CSS custom properties or stylesheets to only the wrapped subtree. This is useful for a local theme adjustment that should not affect matching components elsewhere on the page.

## Usage

### Change a token only inside this subtree

```html preview
<zd-scoped-styles id="local-theme">
  <zd-flex gap="8" wrap>
    <zd-button variant="primary">Locally themed</zd-button>
    <zd-button variant="secondary">Also inside the scope</zd-button>
  </zd-flex>
</zd-scoped-styles>
<zd-button variant="primary">Unchanged outside the scope</zd-button>
<script>
  document.querySelector('#local-theme').css =
    '--zd-button-primary-bg-color: #315a46; --zd-button-primary-fg-color: #ffffff;';
</script>
```

The `.css` property accepts CSS text. Keep overrides scoped to the smallest subtree that needs them, and use tokens from the primitive theme.
