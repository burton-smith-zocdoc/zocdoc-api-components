A push pane reveals supporting content at an edge of the viewport while moving the main page aside. Give it a concise heading and a clear way to close it; use the position that fits the surrounding layout.

## Usage

### A pane with filter controls

```html preview
<zd-push-pane open heading="Display preferences" position="end">
  <p>Choose how the results should be presented.</p>
  <zd-checkbox>Show only available items</zd-checkbox>
  <zd-checkbox>Sort alphabetically</zd-checkbox>
</zd-push-pane>
```

The example starts open to show the pane layout. In an application, open it from a visible control and let the built-in close control dismiss it.
