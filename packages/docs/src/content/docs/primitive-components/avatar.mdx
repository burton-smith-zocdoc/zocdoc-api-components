An avatar presents a compact visual identity using initials or an image. Provide an accessible `label` that describes whose or what profile the avatar represents; initials alone are not an accessible name.

## Usage

### Initials without an external image

```html preview
<zd-flex gap="16" align="center">
  <zd-avatar initials="ZD" label="Sample profile"></zd-avatar>
  <span>Sample profile</span>
</zd-flex>
```

The component renders the provided initials locally, so this example does not request an image from another host.

### Initials with accessible labels

```html preview
<zd-flex gap="16" align="center">
  <zd-avatar initials="A" label="Sample profile A"></zd-avatar>
  <zd-avatar initials="ZD" label="Sample profile ZD"></zd-avatar>
  <zd-avatar initials="DOC" label="Sample profile DOC"></zd-avatar>
</zd-flex>
```

Use the accessible `label` to describe the represented profile rather than repeating initials as the name. Set dimensions with the component's theme tokens when a different avatar size is needed.
