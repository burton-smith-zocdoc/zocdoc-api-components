A dialog places a focused task above the current page. Use a visible control to open it, provide a clear heading and body, and include an obvious way to close it in the header or footer.

## Usage

### Open and close a confirmation dialog

```html preview
<zd-button id="open-dialog">Review settings</zd-button>
<zd-dialog id="settings-dialog" heading="Review your settings">
  <p>Check the selected preferences before saving.</p>
  <zd-flex slot="footer" gap="8" justify="end">
    <zd-button id="close-dialog" variant="ghost">Back</zd-button>
    <zd-button id="save-dialog" variant="primary">Save settings</zd-button>
  </zd-flex>
</zd-dialog>
<script>
  const dialogExample = document.querySelector('#settings-dialog');
  document.querySelector('#open-dialog').addEventListener('click', () => dialogExample.show());
  document.querySelector('#close-dialog').addEventListener('click', () => dialogExample.hide());
  document.querySelector('#save-dialog').addEventListener('click', () => dialogExample.hide());
</script>
```

The methods `show()` and `hide()` let the page control the dialog. In a real form, save only after validation succeeds.

### Start open for a static example

```html preview
<zd-dialog open heading="Keyboard guidance">
  <p>Use Tab to move between controls and Escape to close the dialog.</p>
  <div slot="footer"><zd-button>Continue</zd-button></div>
</zd-dialog>
```

Use `open` when a dialog should initially be visible, such as when rendering a state example. A real flow should open it in response to a user action.
