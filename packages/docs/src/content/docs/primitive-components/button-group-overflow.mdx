Use `zd-button-group-overflow` when a related set of actions should collapse into an overflow menu as space becomes limited. Supply ordinary `zd-button` children; the component manages which actions remain visible.

## Usage

### Responsive action group

```html preview
<div class="p-12" style="max-width: 20rem; resize: horizontal; overflow: auto; border: 1px dashed currentColor;">
  <zd-button-group-overflow label="More actions">
    <zd-button variant="secondary">Open</zd-button>
    <zd-button variant="secondary">Duplicate</zd-button>
    <zd-button variant="secondary">Move</zd-button>
    <zd-button variant="secondary">Archive</zd-button>
  </zd-button-group-overflow>
</div>
```

Resize the bordered container to see how the available actions respond. Keep action labels concise and distinguishable when an item moves into the overflow menu.
