A tab is one selectable label in a tabbed interface. Put it inside `zd-tabs` and pair it, in order, with a `zd-tab-panel`; the parent coordinates selection and keyboard navigation.

## Usage

### Tab paired with its content panel

```html preview
<zd-tabs>
  <zd-tab>Overview</zd-tab>
  <zd-tab-panel>Summary information appears in this panel.</zd-tab-panel>
  <zd-tab>Details</zd-tab>
  <zd-tab-panel>Additional details appear in this panel.</zd-tab-panel>
</zd-tabs>
```

Keep each tab adjacent to its matching panel and use concise labels that make sense when read as a set.
