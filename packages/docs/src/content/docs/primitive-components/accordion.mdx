Use an accordion to organize related sections that readers can expand when they need more detail. Place one or more `zd-accordion-item` elements inside it; each item provides a heading and its panel content.

## Usage

### Several expandable sections

```html preview
<zd-accordion>
  <zd-accordion-item heading="Before you begin">
    Review the steps and gather the information you need.
  </zd-accordion-item>
  <zd-accordion-item heading="After you finish">
    You can return to this section to review your choices.
  </zd-accordion-item>
</zd-accordion>
```

Each child item supplies its own heading and default-slot content. Use `open-single` when readers should only be able to keep one panel open at a time.

### Keep only one item open

```html preview
<zd-accordion open-single>
  <zd-accordion-item heading="Email notifications">Receive updates by email.</zd-accordion-item>
  <zd-accordion-item heading="Text notifications">Receive updates by text.</zd-accordion-item>
</zd-accordion>
```

The `open-single` attribute coordinates the child items; without it, items can be opened independently.

### A standalone item that starts open

```html preview
<zd-accordion-item heading="More information" open>
  This item starts expanded. Readers can still collapse it with its heading.
</zd-accordion-item>
```

An accordion item also works on its own. Use the `heading` attribute for a plain-text heading, or the `heading` slot when it needs richer markup. The `open` state can be set declaratively or controlled through the `show()`, `hide()`, and `toggle()` methods.
