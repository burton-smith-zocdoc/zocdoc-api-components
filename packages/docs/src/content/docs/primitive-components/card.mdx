A card groups related content into a distinct surface. Use the `heading` and `subheading` attributes or slots for its title area, the default slot for body content, and the `footer` slot for supporting actions.

## Usage

### Card with heading and action

```html preview
<zd-card heading="Workspace settings" subheading="Manage your preferences">
  <p>Choose how this workspace should display updates and reminders.</p>
  <zd-flex slot="footer" gap="8" justify="end">
    <zd-button variant="ghost">Cancel</zd-button>
    <zd-button variant="primary">Save changes</zd-button>
  </zd-flex>
</zd-card>
```

Use a card to group related information, not as a substitute for page structure. The footer can hold actions that apply to the card’s content.

### Media alongside content

```html preview
<zd-card heading="Design system" media-position="start">
  <zd-icon slot="media" name="info-circle" label="Information"></zd-icon>
  <p>Shared components help keep experiences consistent.</p>
</zd-card>
```

The `media` slot can hold a supporting image or icon. Choose `media-position` to place it relative to the card content.
