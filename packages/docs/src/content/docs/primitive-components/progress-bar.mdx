A progress bar communicates how much of a known task is complete, or that work is continuing when the total is unknown. Provide a descriptive `label` so the progress has context for assistive technology.

## Usage

### Determinate progress

```html preview
<zd-grid gap="16">
  <zd-progress-bar label="Setup progress" value="3" max="5"></zd-progress-bar>
  <zd-progress-bar label="Upload progress" value="68" max="100"></zd-progress-bar>
</zd-grid>
```

For determinate progress, set `value` and `max` from the actual task. The label should describe what is progressing.

### Indeterminate progress

```html preview
<zd-progress-bar indeterminate label="Checking settings"></zd-progress-bar>
```

Use `indeterminate` when completion time or total work is not known. Do not imply a percentage when the component cannot determine one.
