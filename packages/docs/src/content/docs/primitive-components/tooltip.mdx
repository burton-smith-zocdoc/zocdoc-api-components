A tooltip provides brief supplementary information for an anchor, typically on hover or focus. Put the anchor element in the default slot and the tooltip text in the `content` slot; do not use a tooltip as the only place essential instructions appear.

## Usage

### Supplementary help for a control

```html preview
<zd-tooltip placement="top">
  <zd-button variant="secondary">Display options</zd-button>
  <span slot="content">Choose how items are arranged on this page.</span>
</zd-tooltip>
```

The tooltip is available through interaction with its anchor. Keep the message short and ensure important instructions are also available in the surrounding page content.
