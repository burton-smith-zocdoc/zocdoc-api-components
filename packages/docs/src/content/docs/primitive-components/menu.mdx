A menu presents a compact list of related actions. Put the control that opens it in the `trigger` slot and add `zd-menu-item` or `zd-menu-group` children for the available options.

## Usage

### Action menu

```html preview
<zd-menu placement="bottom-start">
  <zd-button slot="trigger" variant="secondary">More actions</zd-button>
  <zd-menu-item>Rename</zd-menu-item>
  <zd-menu-item>Duplicate</zd-menu-item>
  <zd-menu-item>Archive</zd-menu-item>
  <zd-menu-item disabled>Delete unavailable item</zd-menu-item>
</zd-menu>
```

The menu handles its popup behavior and keyboard interaction. Use plain menu items for actions and set `href` on an item that navigates. Reserve the disabled and selected states for cases where they reflect the current interface.

### Grouped choices

```html preview
<zd-menu placement="bottom-start">
  <zd-button slot="trigger" variant="secondary">Display options</zd-button>
  <zd-menu-group heading="Density" select="single">
    <zd-menu-item>Comfortable</zd-menu-item>
    <zd-menu-item>Compact</zd-menu-item>
  </zd-menu-group>
</zd-menu>
```

Use a group heading to give related menu items context. Set `select="single"` for a one-at-a-time choice or `select="multiple"` for independent selections.
