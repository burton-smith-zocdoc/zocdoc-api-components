A spinner indicates ongoing work when a task does not have a meaningful measurable percentage. Provide a descriptive `label` and, when useful, nearby visible text so the status is clear.

## Usage

### Inline loading status

```html preview
<zd-flex gap="12" align="center">
  <zd-spinner label="Loading results"></zd-spinner>
  <span>Loading results…</span>
</zd-flex>
```

The label gives the indicator an accessible name; visible text also makes the status clear without relying on animation.
