Use `zd-button` for an action or navigation link. Set a `variant` to establish visual emphasis, use `size="small"` for compact contexts, and prefer visible text over icon-only controls.

## Usage

### Variants, density, and state

```html preview
<zd-flex gap="8" wrap align="center">
  <zd-button variant="primary">Continue</zd-button>
  <zd-button variant="secondary">Save for later</zd-button>
  <zd-button variant="ghost">Cancel</zd-button>
  <zd-button variant="destructive">Remove item</zd-button>
  <zd-button variant="link">Learn more</zd-button>
  <zd-button variant="primary" size="small">Compact action</zd-button>
  <zd-button variant="primary" disabled>Unavailable</zd-button>
</zd-flex>
```

Reserve the primary treatment for the main action. Set `disabled` when an action cannot currently be performed.

### Icons and toggle buttons

```html preview
<zd-flex gap="8" wrap align="center">
  <zd-button variant="primary">
    <zd-icon slot="start" name="calendar" label="Calendar"></zd-icon>
    Choose a date
  </zd-button>
  <zd-button variant="secondary" toggle aria-label="Pin this item">Pin</zd-button>
  <zd-button variant="secondary" toggle pressed>Notifications on</zd-button>
</zd-flex>
```

Icons can use the `start` and `end` slots. A toggle button exposes its pressed state; provide a label that still makes sense when the state changes.
