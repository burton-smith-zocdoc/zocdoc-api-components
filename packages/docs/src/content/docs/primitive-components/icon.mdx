An icon adds a compact visual cue from the configured icon set. Choose a supported `name`; provide `label` when the icon conveys information by itself, and treat icons next to equivalent text as decorative.

## Usage

### Icons with visible labels

```html preview
<zd-flex gap="16" wrap>
  <span><zd-icon name="calendar" label="Calendar"></zd-icon> Schedule</span>
  <span><zd-icon name="location-pin" label="Location"></zd-icon> Location</span>
  <span><zd-icon name="checkmark" label="Complete"></zd-icon> Complete</span>
</zd-flex>
```

The examples use icons included in the configured set and keep each meaning visible as text. For icon-only controls, give the control itself an accessible name.

### Size and rotation

```html preview
<zd-flex gap="16" align="center">
  <zd-icon name="info-circle" label="Information" size="small"></zd-icon>
  <zd-icon name="info-circle" label="Information"></zd-icon>
  <zd-icon name="info-circle" label="Information" size="large"></zd-icon>
  <zd-icon name="chevron-right" label="Next" rotate="90"></zd-icon>
</zd-flex>
```

When size is omitted, the icon scales with the surrounding text. Explicit sizes use theme tokens.

## Available icons

Every icon in the configured set. Hover an icon to see its `name`.
