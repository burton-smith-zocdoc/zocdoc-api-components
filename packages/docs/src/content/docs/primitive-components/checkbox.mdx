A checkbox represents an independently selectable option. Supply visible label text in its default slot, and use a checked checkbox or the indeterminate state only when it reflects the actual selection state.

## Usage

### Optional preferences

```html preview
<zd-grid gap="12">
  <zd-checkbox>Include weekend options</zd-checkbox>
  <zd-checkbox checked>Send a summary by email</zd-checkbox>
  <zd-checkbox indeterminate>Some categories selected</zd-checkbox>
  <zd-checkbox disabled>Unavailable option</zd-checkbox>
</zd-grid>
```

The default slot provides the visible label. `indeterminate` is useful for a parent selection that includes some, but not all, child choices.

### Help and validation text

```html preview
<zd-grid gap="16">
  <zd-checkbox help-text="You can change this preference later.">Remember this choice</zd-checkbox>
  <zd-checkbox required invalid error-message="Select this option to continue.">I agree to the terms</zd-checkbox>
</zd-grid>
```

Keep errors near the related control and explain how to resolve them. Required and invalid states should match the form’s actual validation.
