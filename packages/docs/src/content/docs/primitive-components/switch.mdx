A switch is a labeled on/off control for a setting that takes effect immediately. Use it for a single binary preference, not as a replacement for a submit-once checkbox in a form.

## Usage

### Toggle a preference

```html preview
<zd-grid gap="16">
  <zd-switch label="Enable email reminders"></zd-switch>
  <zd-switch label="Enable desktop notifications" checked>
    <span slot="checked-message">On</span>
    <span slot="unchecked-message">Off</span>
  </zd-switch>
</zd-grid>
```

The visible `label` names the setting. Optional checked and unchecked messages can make the current state explicit.
