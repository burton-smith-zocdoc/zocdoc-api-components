A select lets a reader choose one or more values from a list of native `<option>` elements. Provide a visible `label`, make the options understandable out of context, and use `required` when a selection is mandatory.

## Usage

### Labeled select with options

```html preview
<zd-select label="Notification preference" name="notification" value="email" required>
  <option value="">Choose a preference</option>
  <option value="email">Email</option>
  <option value="text">Text message</option>
  <option value="none">No preference</option>
</zd-select>
```

Use the normal HTML `option` elements and values. The `size` property is the native visible-row count, not the compact density used by other form controls.

### Helper and error text

```html preview
<zd-select
  label="Display format"
  name="format"
  help-text="Choose the format used for this view."
  required
  invalid
  error-message="Choose a display format."
>
  <option value="">Select a format</option>
  <option value="list">List</option>
  <option value="calendar">Calendar</option>
</zd-select>
```

Show validation feedback only when the field has actually been checked. Keep the visible label even when help or error text is present.
