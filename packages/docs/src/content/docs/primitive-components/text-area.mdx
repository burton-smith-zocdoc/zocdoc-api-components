Use `zd-text-area` when a reader needs to enter multiple lines of text. Provide a visible label and set useful length constraints when appropriate; explain the expected content without relying on placeholder text alone.

## Usage

### Labeled multiline field

```html preview
<zd-text-area
  label="Additional project notes"
  name="notes"
  placeholder="Add a short note"
  help-text="Keep the note concise."
  maxlength="500"
></zd-text-area>
```

The label remains visible as the field is edited. Use `maxlength` when the application has a real content limit.

### Validation feedback

```html preview
<zd-text-area
  label="Reason for request"
  name="reason"
  required
  invalid
  error-message="Add a short explanation to continue."
>
</zd-text-area>
```

Set `invalid` and its message from actual validation. Use `reportValidity()` or the form’s validation flow when appropriate.
