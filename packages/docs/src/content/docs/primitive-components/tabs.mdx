Use `zd-tabs` to coordinate a tab list and its corresponding panels. Add matching `zd-tab` and `zd-tab-panel` children in order, and use the `layout` property when a vertical tab list works better for the available space.

## Usage

### Horizontal tabs

```html preview
<zd-tabs>
  <zd-tab>Overview</zd-tab>
  <zd-tab-panel>Summary information appears here.</zd-tab-panel>
  <zd-tab>Details</zd-tab>
  <zd-tab-panel>Additional information appears here.</zd-tab-panel>
  <zd-tab>History</zd-tab>
  <zd-tab-panel>Earlier changes appear here.</zd-tab-panel>
</zd-tabs>
```

The active tab changes the displayed panel. Keep tab and panel order aligned and ensure every panel has a useful heading or introductory content.

### Vertical layout

```html preview
<zd-tabs layout="vertical">
  <zd-tab>Overview</zd-tab>
  <zd-tab-panel>Summary information appears here.</zd-tab-panel>
  <zd-tab>Details</zd-tab>
  <zd-tab-panel>Additional information appears here.</zd-tab-panel>
</zd-tabs>
```

Use vertical layout when there is enough room for a side-by-side list and panel. Arrow-key navigation is managed by the component.
