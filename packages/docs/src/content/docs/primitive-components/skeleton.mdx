A skeleton is a placeholder for content that is loading. Match its shape and approximate dimensions to the content it replaces, and keep an accessible loading status elsewhere when users need to know what is happening.

## Usage

### Text and profile placeholders

```html preview
<zd-card heading="Loading profile">
  <zd-flex gap="16" align="center">
    <zd-skeleton shape="circle" style="width: 3rem; height: 3rem;"></zd-skeleton>
    <zd-grid gap="8" style="flex: 1;">
      <zd-skeleton style="width: 65%; height: 1rem;"></zd-skeleton>
      <zd-skeleton style="width: 40%; height: 0.875rem;"></zd-skeleton>
    </zd-grid>
  </zd-flex>
  <zd-skeleton style="width: 100%; height: 1rem;"></zd-skeleton>
</zd-card>
```

Set dimensions to reflect the future content layout. Pair placeholders with a live loading announcement when loading state needs to be communicated.
