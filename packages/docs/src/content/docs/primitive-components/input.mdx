Use `zd-input` for a single-line value. Provide a visible `label`, select the appropriate native input `type`, and use help or error text to explain what the field expects.

## Usage

### Labeled input with helper text

```html preview
<zd-input
  label="Search by city or ZIP code"
  name="location"
  type="text"
  autocomplete="postal-code"
  help-text="Enter a city name or a five-digit ZIP code."
></zd-input>
```

A visible label is required; placeholder text alone does not label a field. `autocomplete` can help the browser suggest an appropriate value.

### Required field with validation feedback

```html preview
<zd-input
  label="Email address"
  name="email"
  type="email"
  required
  invalid
  error-message="Enter an email address in the expected format."
></zd-input>
```

Set `invalid` and `error-message` from your actual validation result. Use the component’s validity methods when integrating with a form.
