A popup is a low-level positioning primitive for floating content relative to an anchor. Use the `anchor` slot for an anchor inside the popup, or the `anchor` property to target an element elsewhere on the page.

## Usage

### Position a panel under its anchor

```html preview
<zd-popup open placement="bottom-start" distance="8" arrow>
  <zd-button slot="anchor" variant="secondary">Options</zd-button>
  <zd-card heading="Available options">
    <p>Positioned content stays aligned with its anchor.</p>
  </zd-card>
</zd-popup>
```

This preview starts open so the placement is visible. In an application, control `open` or call `show()` and `hide()` in response to user actions.

### Use a fallback when space is limited

```html preview
<zd-popup open placement="top" flip shift flip-fallback-placements="bottom start end">
  <zd-button slot="anchor" variant="secondary">Show details</zd-button>
  <zd-card>Use `flip` and `shift` to keep the panel in view.</zd-card>
</zd-popup>
```

Placement is a preference: the popup can flip or shift to remain inside its configured boundary.
