Use `zd-overflow` for a row of items that should collapse when their container cannot fit them all. Any content can be placed in the default slot; a menu trigger gives readers access to hidden items.

## Usage

### Overflowing labels in a resizable region

```html preview
<div class="p-12" style="max-width: 18rem; resize: horizontal; overflow: auto; border: 1px dashed currentColor;">
  <zd-overflow label="Show remaining categories" min="1">
    <zd-badge>Design</zd-badge>
    <zd-badge>Engineering</zd-badge>
    <zd-badge>Research</zd-badge>
    <zd-badge>Accessibility</zd-badge>
    <zd-badge>Documentation</zd-badge>
  </zd-overflow>
</div>
```

Resize the container to see items move into the overflow menu. Set `min` when a minimum number of items must remain visible.
