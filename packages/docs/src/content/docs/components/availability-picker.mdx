The `<zd-availability-picker>` component lets patients select a specific appointment time.

## Usage

```html preview
<zd-availability-picker
  provider-location-id="pr_abc123-def456_wxyz7890|lo_abc123-def456_wxyz7890"
  visit-reason-id="pc_FRO-18leckytNKtruw5dLR"
></zd-availability-picker>
```

## Examples

### Strip Layout

Horizontal day tabs with times below:

```html preview
<zd-availability-picker
  provider-location-id="pr_abc123-def456_wxyz7890|lo_abc123-def456_wxyz7890"
  visit-reason-id="pc_FRO-18leckytNKtruw5dLR"
  layout="strip"
></zd-availability-picker>
```

### Stacked Layout

All days shown vertically:

```html preview
<zd-availability-picker
  provider-location-id="pr_abc123-def456_wxyz7890|lo_abc123-def456_wxyz7890"
  visit-reason-id="pc_FRO-18leckytNKtruw5dLR"
  layout="stacked"
></zd-availability-picker>
```

## Attributes

| Attribute | Type | Default | Description |
|-----------|------|---------|-------------|
| `provider-location-id` | `string` | — | Provider to show availability for |
| `visit-reason-id` | `string` | — | Visit reason filter |
| `layout` | `'strip' \| 'stacked'` | `'strip'` | Layout mode |
| `hide-patient-type` | `boolean` | `false` | Hide the New/Existing patient control |
| `start-date` | `string` | today | First day to request, as `YYYY-MM-DD` |
| `days` | `number` | `7` | Number of days to request (max 30) |
| `selected-start-time` | `string` | — | Pre-select a slot by its start time |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `slot-select` | `{ startTime, providerLocationId }` | Slot clicked |
| `patient-type-change` | `{ patientType: 'new' \| 'existing' }` | Patient type toggled |
| `availability-error` | `{ error }` | Fetch failed |

## Zocdoc API

Renders timeslots from `GET /v1/provider_locations/availability`. The host (or `<zd-booking>`) fetches them. The API limits a window to 30 days and guarantees availability up to 150 days out. Each slot's `start_time` must be passed to booking unchanged. See [Find Provider Availability and Book Appointments](https://api-docs.zocdoc.com/guides/patient/book-appointments).

## Accessibility

- Slots are buttons with full datetime labels
- Selected slot announced
- Day tabs use `role="tablist"` pattern

| `--zd-picker-columns` | `4` | Slots per row |
