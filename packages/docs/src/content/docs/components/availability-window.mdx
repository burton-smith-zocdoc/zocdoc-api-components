The `<zd-availability-window>` component provides previous/next navigation for availability date ranges.

## Usage

```html preview
<zd-availability-window id="date-window" can-go-earlier></zd-availability-window>
<script>
  const dateWindow = document.getElementById('date-window');
  const startDate = new Date();
  const endDate = new Date(startDate);
  endDate.setDate(endDate.getDate() + 6);
  const toDateKey = (date) => {
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const day = String(date.getDate()).padStart(2, '0');
    return `${year}-${month}-${day}`;
  };
  dateWindow.setAttribute('start-date', toDateKey(startDate));
  dateWindow.setAttribute('end-date', toDateKey(endDate));
</script>
```

## Accessibility

- Buttons labeled "Earlier dates" and "Later dates"
- Disabled state properly announced
- Current range visible as text
