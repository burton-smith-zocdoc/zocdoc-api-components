The `<zd-provider-profile>` component displays complete provider details including about section, education, and contact information.

## Usage

```html preview
<zd-provider-profile id="provider-profile"></zd-provider-profile>
<script>
  const providerProfile = document.getElementById('provider-profile');
  providerProfile.provider = {
    provider_location_id: 'pr_abc123-def456_wxyz7890|lo_abc123-def456_wxyz7890',
    provider_location_type: 'in_person_provider',
    provider: {
      provider_id: 'pr_abc123-def456_wxyz7890',
      first_name: 'Avery',
      last_name: 'Sandoval',
      title: 'MD',
      specialties: ['Primary Care Doctor'],
      provider_photo_url: '/zocdoc-api-components/images/michael-scott.png',
      statement: 'I have practised primary care in Brooklyn for twelve years.',
      languages: ['English', 'Spanish'],
      credentials: {
        certifications: ['American Board of Family Medicine'],
        education: { institutions: ['Sandbox University School of Medicine'] },
      },
    },
    practice: { practice_id: 'pt_abc123-def456_wxyz7890', practice_name: 'Sandbox Health Partners' },
    location: {
      location_name: 'Sandbox Plaza Family Medicine',
      address1: '1 Sandbox Plaza',
      city: 'Brooklyn',
      state: 'NY',
      zip_code: '11201',
      phone_number: '(555) 555-0100',
      time_zone: 'America/New_York',
    },
  };
</script>
```

## Markup

The `provider` can be written into the HTML as a JSON block instead of set by script:

```html preview
<zd-provider-profile>
  <script type="application/json" data-zd-prop="provider">
    {
      "provider_location_id": "pr_abc123-def456_wxyz7890|lo_abc123-def456_wxyz7890",
      "provider_location_type": "in_person_provider",
      "provider": {
        "provider_id": "pr_abc123-def456_wxyz7890",
        "first_name": "Avery",
        "last_name": "Sandoval",
        "title": "MD",
        "specialties": ["Primary Care Doctor"],
        "provider_photo_url": "/zocdoc-api-components/images/michael-scott.png",
        "statement": "I have practised primary care in Brooklyn for twelve years.",
        "languages": ["English", "Spanish"]
      },
      "practice": { "practice_id": "pt_abc123-def456_wxyz7890", "practice_name": "Sandbox Health Partners" },
      "location": {
        "location_name": "Sandbox Plaza Family Medicine",
        "address1": "1 Sandbox Plaza",
        "city": "Brooklyn",
        "state": "NY",
        "zip_code": "11201",
        "time_zone": "America/New_York"
      }
    }
  </script>
</zd-provider-profile>
```

See [Markup and Supplied Data](/zocdoc-api-components/guides/markup-and-supplied-data/).

## Accessibility

- Sections use semantic headings (h2, h3)
- Contact info linked appropriately (tel:, mailto:)
- Missing sections are omitted, not empty

